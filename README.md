# Scrolling Vertical Bars

A Next.js application featuring "Woven Records" - an interactive canvas animation that transforms text into a digital textile of scrolling vertical bars.

## Features

- Interactive canvas-based animation with scrolling vertical bars
- Customizable text input - enter your own characters to weave into the pattern
- Smooth, continuous animation using requestAnimationFrame
- Responsive design with centered layout

## Getting Started

### Prerequisites

- Node.js 18.x or later
- pnpm (recommended) or npm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd scrolling-vertical-bars
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Run the development server:
   ```bash
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `pnpm dev` - Start the development server
- `pnpm build` - Build the application for production
- `pnpm start` - Start the production server
- `pnpm lint` - Run ESLint
